Degrading retrieval did not increase hallucination

A controlled study of what a retrieval-augmented system does when its evidence gets worse. Accuracy fell by 12 points. Fabrication did not move at all.

Study in progress 4 of 5 noise levels collected 0 invalid generations Hypotheses preregistered
As the share of the context window filled with plausible-but-wrong passages rose from 0% to 75%, correct answers fell from 96 to 78 of 150. Unsupported assertions stayed at 7, 6, 7, 7.
Δ accuracy at 75% corruption −12.0 pts [−18.0, −7.3] · p < 0.0001
Δ hallucination at 75% corruption ±0.0 pts [−2.7, +2.7] · p = 1.00

Both figures are paired bootstraps over the same 150 questions, so per-question difficulty cancels. The hallucination result is not a weak trend — it is a null bounded within ±2.7 points, measured against an accuracy collapse four times that size.

Accounting

The 18 correct answers that were lost

−18correct answers lost between 0% and 75% corruption
+13became abstentions — the system said it could not answer
+5became wrong-but-grounded — it faithfully reported the bad passage
0became fabrications

This is invisible to any analysis that scores answers as merely right or wrong. A pooled report says failures rose from 54 to 72 and stops. Separating an unsupported assertion from a faithful report of bad evidence is what makes the null visible — and that separation was the study's central design decision.

Integrity

What this does not show

The preregistered hypothesis failed

We predicted silent failure would peak at partial corruption. Observed: 0.185, 0.203, 0.219, 0.208 — an interior bump, but with intervals of [0.09, 0.30] and [0.12, 0.33] that overlap completely. A power analysis run before data collection said separating a peak at n=150 needs a gap above 16 points. The observed spread is 3. Reported as unsupported.

Bounds on the claim

  • One generator, one retriever, one noise type
  • n=150; unsupported counts of 6–7 make the level imprecise even though the difference is tight
  • The 100% corruption condition has not run yet
  • Perturbations are synthetic; a manipulation check against naturally failed retrievals is pending
Method

How it was measured

600 SQuAD v2 questions (70% answerable / 30% unanswerable, seed 20240617) over a 1,330-chunk corpus built from all 1,204 development paragraphs. Corruption is applied to the context handed to the generator, never to the shared index — so the dose each individual answer received is exact and known, which a poisoned index cannot give you.

Generation and judging use different models, so faithfulness verdicts are not self-evaluation. Retrieval runs locally, making that half of the pipeline reproducible without an API key.

Generatorgemini-3.5-flash-lite, temperature 0
Judgegemini-3.1-flash-lite — different model, self_eval: false
Retrieverall-MiniLM-L6-v2, exact inner product over FAISS
StatisticsPaired bootstrap, 2000 resamples, clustered by question
